# dlsite bash
bash scripts to fetch and download contents from dlsite

## requirements
- bash
- jq
- sqlite3
- dialog (for tui)
## usage
### login and fetch info
- copy `config.sh.example` to `config.sh` and set your username
- run `login.sh` (you will be prompted for your password interactively)
- fetch-purchased.sh
- fetch-info.sh

### download contents
